初始化与数据入库

在本地克隆仓库，启动虚拟环境并创建 SQLite 数据库。

pip install -r requirements.txt
python scripts/init_db.py
python scripts/ingest.py data/utf8.txt --to-db \
  --doc-title "边城纪事" --chapter "第1章" --chunk-size 1200

调用 Python 助手

利用 NovelAssistant 体验自由创作、收纳与审稿。

python - <<'PY'
from scripts.assistant import NovelAssistant
assistant = NovelAssistant()
print(assistant.free_write("写段小说来看看吧？"))
assistant.collect_text("边城纪事", "第1章", "阿黎在码头等船…")
print(assistant.inspire("边城纪事", hint="雨夜"))
PY

部署到 GitHub Pages

将 docs/index.html 提交到主分支，随后在仓库设置中启用 Pages（Source 选择 docs/）。

  • 仓库 → Settings → Pages → Source 选择 Deploy from a branch
  • Branch 选择 main，目录选择 /docs
  • 等待构建完成，即可在线分享演示地址
构建于 AInovelAssist · 静态前端仅用于演示，真实功能请在本地或服务器运行 Python 后端。
